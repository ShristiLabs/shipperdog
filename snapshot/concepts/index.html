Concepts ​

Deep dives into how ShipperDog works — the models behind every screen. Read them in any order; each stands alone and links to the others.

  • Architecture — the platform at a glance: three surfaces, one API, and the engines underneath
  • Tenancy and isolation — organizations, tenants, and isolation by construction
  • Release lifecycle — the eleven-edge state machine every release walks
  • Rings and rollout — the progressive distribution ladder and the governed hop
  • Approvals and gates — sign-off chains and quality gates as configurable data
  • Artifact pipeline — upload, extraction, and the seven-stage validation to READY
  • Authorization — roles, the seven-layer decision chain, and how testers get access
  • Identity and SSO — OIDC, SAML, SCIM, and how corporate identity fits in
  • Feedback and analytics — the closed loop from tester reports to promotion decisions
  • Security model — immutability, signed URLs, concealment, and the audit trail

New to ShipperDog? Start with core concepts and the platform tour instead — this section is the reference behind them.

Developer internals (API reference, module documentation, ADRs) live in the shipperdog repository's docs directory; these pages link there for depth rather than duplicating it.

# How-To

Task guides, grouped by surface:

- **Console** — orgs, tenants, apps, versions and tags, environments, releases, approvals, quality gates, rings and promotion, staged rollout, rollback, feedback triage, devices, analytics, notifications, distribution channels, ABAC policies, SSO, SCIM provisioning, SIEM streams, audit log.
- **Portal** — tester how-tos: accept an invite, browse apps, install on iOS, install on Android, submit feedback.
- **Automation** — the CLI and CI integrations: CLI reference, GitHub Actions, Jenkins, GitLab, webhooks, companion app.

These guides land in the WP5 and WP6 rollouts of the documentation plan.

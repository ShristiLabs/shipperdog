# Install on Android

From any version page, tap **Download Android build**. The portal
first checks you may have this build, then shows one short screen
before the file arrives.

![The download screen shown before the install](/screenshots/portal/download-guidance.png)

1. **Read the one-time permission note.** Android asks for a
   permission before a browser can install an app. If the download
   does not install automatically: open **Settings**, then **Apps**,
   then your browser (Chrome), then **Install unknown apps**, and
   allow installs from this source. You only ever do this once per
   browser.

2. **Tap `Continue to download`.** The app file (an APK) downloads
   straight from the portal's secure link — the screen shows the
   file name, its size, and how long the link stays valid (a few
   minutes; if it lapses, just tap Download again for a fresh one).

3. **Open the file** (from the notification or your Downloads) and
   confirm the install. Android shows its own install screen — that
   final confirm is your phone's design, not the portal's.

::: tip
If the portal says **This build is not available**, the team pulled
the build or your access changed — ask them, or tap Retry if you
were mid-flow.
:::
